# Modèle IA — COBOL

**Statut initial : NOT_IMPLEMENTED.** Cette piste indépendante vise à construire un modèle dans COBOL; aucun modèle entraîné n'est livré par ce fichier.

## Objectif
Piste expérimentale : démontrer un modèle numérique entraînable.

## Travail requis
1. Vérifier et enregistrer la toolchain et les dépendances disponibles.
2. Implémenter les opérations numériques dans ce langage et tester contre les vecteurs communs.
3. Construire un modèle causal minimal entraînable, dans les limites de la cible.
4. Entraîner sur données synthétiques/licenciées avec séparation train/validation/test.
5. Sauvegarder/recharger les poids et vérifier l'inférence.
6. Enregistrer commandes, versions, journaux, hashes, temps, mémoire, limites et résultats dans `STATUS.md`.

La documentation, un squelette ou l'appel à un modèle externe ne suffit pas. Spécification : [../../MODEL-SPEC.md](../../MODEL-SPEC.md).
